YouTube Transcript RAG Chatbot

Chrome extension that answers questions about any YouTube video using only its transcript.

  • API docs ↗ — YouTube Transcript RAG Chatbot (opens in a new tab)
  • GitHub ↗ — YouTube Transcript RAG Chatbot (opens in a new tab)
  • TODO: Chrome Web Store or demo video (optional)

Problem

Long videos are hard to search; viewers want answers from the video itself without scrubbing through it.

What I built

  • Manifest V3 Chrome extension with DOM transcript extraction
  • FastAPI backend with LangServe routes for Q&A and a dedicated summarization path

Architecture

Pipeline

  1. YouTube page
  2. Transcript extraction (extension)
  3. FastAPI backend
  4. Recursive chunking
  5. OpenAI embeddings
  6. FAISS search
  7. Answer / Summary (LangServe routes)
  8. Extension UI

Supporting

  • Per-IP rate limiting
  • LRU-capped vector store
  • Automatic re-indexing

Key engineering decisions

  1. Per-IP rate limiting to protect a shared backend
  2. LRU-capped vector store to bound memory
  3. Automatic re-indexing so the service survives free-tier cold starts on Render

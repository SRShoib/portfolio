SupportLens

End-to-end NLP platform that turns raw support tickets into structured intelligence: classification, entities, sentiment, topics, search and RAG-drafted replies.

Problem

Support teams sit on thousands of unstructured tickets; finding what is urgent, what customers are asking about, and how to reply takes manual triage.

What I built

  • Intent and urgency classification, entity extraction, sentiment trajectories, summarization, topic discovery, semantic search and RAG-drafted replies
  • Next.js metrics dashboard backed by a PostgreSQL-persisted evaluation harness with live drift monitoring

Architecture

Pipeline

  1. Tickets
  2. Classification (intent, urgency)
  3. Entity extraction
  4. Sentiment
  5. Summarization
  6. Topic discovery (BERTopic)
  7. Hybrid retrieval (dense embeddings + cross-encoder rerank)
  8. Citation-grounded reply drafts
  9. Dashboard

Supporting

  • PostgreSQL eval harness
  • Drift monitoring
  • Budget-capped LLM client

Key engineering decisions

  1. Benchmarked classical baselines against fine-tuned transformers for each task and deployed the winner. It was not a uniform transformer win: the baseline won intent classification (0.9990 vs. 0.9975 macro-F1) and rules won NER overall (0.585 vs. 0.447)
  2. Hybrid retrieval with cross-encoder reranking
  3. Budget-capped LLM client

Evaluation & results

  • +0.115 macro-F1 on urgency classification (0.794 → 0.910; TF-IDF + LinearSVC baseline → DeBERTa-v3-small)
  • +0.17 ROUGE-1 on summarization (FLAN-T5)
  • Retrieval hit-rate@5: 0.920
  • Total LLM spend under $0.04

Datasets used

Bitext Customer Support (Hugging Face)
27 intents, about 27k utterances — used to train intent classification
Customer Support on Twitter (Kaggle, about 3M tweets)
unlabeled real-world text, used for cleaning, clustering, search and drift analysis
tweet_eval (sentiment/emotion)
transfer learning for sentiment and emotion models
samsum / dialogsum
transfer learning for thread summarization
Synthetic NER set (generated) plus a 200-example hand-checked gold set
entity extraction for ORDER_ID, PRODUCT, DATE, AMOUNT and ACCOUNT_REF
Urgency labels
no existing dataset has these; rule-based labels plus up to 2,000 LLM-generated labels

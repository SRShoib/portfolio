Enterprise Knowledge Assistant

Enterprise RAG assistant for internal documents, with role-aware retrieval, cited answers and quality monitoring.

Problem

Teams need to search internal documents quickly, but every answer must be traceable to its source, and users must only see content they are authorized to access.

What I built

  • Document upload with automated ingestion
  • Citation-aware chat workspace with confidence indicators
  • Admin dashboard showing usage metrics and low-confidence queries
  • JWT authentication with 4-role RBAC, chat history, feedback capture and audit logging

Architecture

Pipeline

  1. Upload (PDF / DOCX / TXT)
  2. Parsing
  3. Recursive chunking
  4. OpenAI embeddings
  5. Pinecone index
  6. Role-filtered retrieval
  7. LLM answer with citations + confidence
  8. Chat workspace

Supporting

  • JWT auth + RBAC
  • PostgreSQL (history, feedback, audit log)
  • LangSmith tracing
  • RAGAS-style evaluation endpoint

Key engineering decisions

  1. Role filtering happens at retrieval time, so unauthorized content never reaches the model
  2. Confidence indicators, plus an admin view of low-confidence queries to find gaps
  3. Evaluation endpoint and LangSmith tracing to monitor answer quality over time
